# מזון, גוף ונפש

**[לאפליקציה החיה: tzuna-gh.vercel.app](https://tzuna-gh.vercel.app)**
המיזוג האחרון, בלי Vercel: [raw.githack](https://raw.githack.com/Anat1969/Tzuna-GH/main/index.html) (ב"One more step" לוחצים פעם אחת "Open the page").

זיקוק תורה לכדי הכרה, הבנה ושימוש.

לא מאגר. לא ספר. לא אתר תוכן.
כלי קטן שמלמד לראות: מה זה, איך זה עובד, מה מתאים למה, ומה נשאר לא ידוע.

## מה יש בפנים
- **מצפן (בית):** שלוש שכבות על דוגמה אחת, ומבחן דקה: לאיזו שכבה שייכת הטענה?
- **מזון:** 33 גיליונות הרבריום. לכל אחד הכרה, הבנה ושימוש, וקישור למתכונים.
- **מתכונים:** 6 מתכונים, עד 10 שלבים, מקור מסורת לכל אחד, וטבלת "שנה במטבח".
- **עץ הזית:** תלת־ממד עם חמש נקודות לחיצה, ומיקרו ומאקרו.
- **עונות:** גלגל של שנה. כל טבעת היא מזון אחד.
- **השוואה:** שכבה מול שכבה, ו"מה משותף" שנגזר מהדאטה.
- **רשימה אדומה, עזרה, שיטה ומקורות.**
- **שכבת בטיחות:** מילות חירום בחיפוש פותחות מיד את קווי העזרה.

## עקרונות
1. פחות מילים, יותר מבנה.
2. כל דבר נראה לפני שהוא נקרא: תמונה, סכמה, מבנה תלת-ממדי.
3. שלוש שכבות בלבד בכל פריט: ידוע, נאמר, מאמינים.
4. אין ייעוץ רפואי, אין מינונים, אין יעדי קלוריות.
5. כל טענה מתועדת. מה שלא נבדק מסומן כך.

## הרצה
אתר סטטי בלי שלב בנייה.

```bash
python3 -m http.server 8090
```

```bash
npm test
```

`npm test` מריץ את בדיקת הדאטה (`scripts/lint-data.mjs`) ובדיקת קצה לקצה (`tests/e2e.cjs`, Playwright).
