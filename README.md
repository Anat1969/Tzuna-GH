# מזון, גוף ונפש

זיקוק תורה לכדי הכרה, הבנה ושימוש.

לא מאגר. לא ספר. לא אתר תוכן.
כלי קטן שמלמד לראות: מה זה, איך זה עובד, מה מתאים למה, ומה נשאר לא ידוע.

## עקרונות
1. פחות מילים, יותר מבנה.
2. כל דבר נראה לפני שהוא נקרא: תמונה, סכמה, מבנה תלת-ממדי.
3. שלוש שכבות בלבד בכל פריט: ידוע, נאמר, מאמינים.
4. אין ייעוץ רפואי, אין מינונים, אין יעדי קלוריות.
5. כל טענה מתועדת. מה שלא נבדק מסומן כך.

## מסמכים בריפו
- CLAUDE.md: הוראות לקלוד קוד (קרא ראשון)
- docs/SPEC.md: מה בונים ולמה
- docs/SAFETY.md: כללי בטיחות (חובה לפני כל תוכן)
- docs/CONTENT_RULES.md: חוקי ניסוח
- docs/DATA_MODEL.md: מבנה הנתונים
- docs/SOURCES.md: מקורות מאומתים
- docs/ROADMAP.md: שלבי בנייה
- docs/VISUAL.md: שפה ויזואלית

## הפעלה
כל שינוי בתוכן עובר בדיקה מול docs/SAFETY.md ו-docs/CONTENT_RULES.md לפני מיזוג.
